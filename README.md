# keepsakes-web

Keepsakes (keepsakes.gift): a couple's photos become a private 3D "Museum of Us", walkable in the browser alone or together.

- `BUILD_SPEC.md`: what we build, step by step
- `CLAUDE.md`: rules for Claude Code
- `PROGRESS.md`: where we are
- `assets-src/blender/museum.blend`: the museum (made by hand) + `BLENDER_GUIDE.md`
- `web/`: the web experience (Vite + React Three Fiber)
